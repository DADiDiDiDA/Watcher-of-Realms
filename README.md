# Watcher-of-Realms · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 登录游戏**：自动进入游戏
- **🎁 领取商城免费礼包**：领取商城各类免费礼包
- **✉️领取邮件奖励**：领取邮件
- **🎁 领取签到奖励**：领取每日签到奖励
- **⛏️ 矿场领取**：领取矿场
- **🛒 矮人超市购买**：购买一次矮人超市金币商品并执行一次一键购买（需要预设好购买的物品；请保证货币充足！！！！）
- **👥 领取友情点**：领取并赠送友情点
- **💪 友情点换体力**：使用友情点兑换体力
- **⛵ 航海**：启动航海任务；航海任务为上一次派遣目标
- **🚢 休伯利安**：领取每日休伯利安奖励
- **⚔️ 刷体力**：自动刷副本（可在下方选择要刷的副本类型）
- **🌊 魔潮扫荡**：自动扫荡魔潮副本
- **📦 分解角色**：自动遣散一星二星三星角色，以保证英雄数量不会超出仓库
- **🐉 公会巨龙**：挑战两次巨龙
- **📋 领取任务奖励第一次**：领取任务奖励
- **⚡ 装备升级**：自动强化装备至4级；如果每日任务没有强化装备任务，就跳过；请保证你有可升级的装备！！！！
- **🔮 英灵召唤一次**：自动进行一次英灵召唤，如果每日任务没有召唤一次任务，就跳过
- **📋 领取任务奖励第二次**：领取任务奖励
- **🏛️ 公会奖励领取**：领取公会的待领取奖励；不领取工会战奖励！！
- **🎟️ 通行证奖励领取**：通行证奖励领取
- **⏰ 在线奖励领取**：领取在线时长奖励
- **🔄 每周交易所交易**：每周交易所交易
- **🗿 泰坦废墟任务**：自动完成泰坦废墟

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **720 × 1080**
- 开启 **自动战斗 → 后台战斗**
- 矮人商城：**金币购买不提示**
- 背包 → 装备 → 排序方式 → 按 **装备等级 · 升序** 排列

## 新设备需要准备的东西

- 安装 **Python 3** 并加入系统 PATH
- 运行 `DependencySetup_依赖库安装_win.bat` 安装 VC++ 运行库与 .NET 10
- 安装依赖：`pip install psutil pyautogui pygetwindow opencv-python pillow`
- 手动把 `moontonlauncher.lnk` 放到 `assets/resource/agent/` 目录下
